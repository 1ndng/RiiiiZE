# RiiiiZE

模擬手機畫面的網頁遊戲框架（從 sosho 移植功能）：手機密碼鎖、首頁（行事曆小工具）、Instagram、KakaoTalk（含語音通話）、相簿、X、備忘錄。
目前只有功能，所有內容都是佔位用的測試資料，照片全部是 `images/placeholder.jpg`。

- 手機直接開就是滿版；電腦上會顯示成一支手機。
- 新遊戲一開始是鬧鐘響起（7:00，`data.js` 的 `game.alarm`）：往右滑「滑動來停止」進入鎖定畫面，「稍後提醒」過幾秒再響一次。鎖定畫面（滑動以解鎖、時間、KakaoTalk 未讀通知，每則分開顯示）往上滑才輸入密碼；點通知解鎖後直接打開那個聊天室。
- 測試用密碼：手機、KakaoTalk、IG 帳號、相簿「已隱藏」、鎖住的備忘錄都是 `0000`。
- 通話：KakaoTalk 和「好友 A」的聊天室右上角電話鍵 → 會接通測試對話；打開「好友 B」聊天室 6 秒後會有來電。

## 檔案結構

| 檔案 | 用途 |

| `index.html` | 頁面骨架、載入所有程式 |
| `js/game.js` | 遊戲時間（第幾天、早上／放學／晚上、睡覺換日）和存檔（手動好幾格＋每天早上自動存檔） |
| `js/story.js` | 劇情對話框（背景＋逐字出現的對話、選項、對話紀錄）、玩家名字、主線劇情排程 |

| `js/ending.js` | 結局：結局劇情＋後日談＋結局畫面、繼續／重新開始、結局圖鑑 |

## 其他

- **一學年**：2025/9/1（星期一）～2026/8/31。9/1～9/7 是開學週（主線＋強制日程），之後每個月開始時在月曆上安排星期一～六要去哪裡；確認後自動往後跳、照安排加好感。手機只有星期日能用：星期日出現鎖定畫面，解鎖後自由使用手機，晚上按「睡覺」繼續；其他有事的日子（主線、特殊劇情、節日、生日、14 日送禮）不解鎖手機，直接在黑底日期畫面上播劇情，播完自動往後跳。設定都在 `data.js` 的 `plan`。桌布的月曆可以用 ‹ › 翻月份（9 月～隔年 8 月）
- **隱藏數值**：好感度（玩家對每位成員）、成員之間的關係（兩兩一組）、覺醒度。成員寫在 `data.js` 的 `cast`；選項、訊息回覆、電話段落寫 `effects` 改數值，劇情、訊息、電話、行事曆行程寫 `if` 加條件（格式寫在 `cast` 上面的註解）。開發時可以在 設定 → 數值（開發用）查看、調整、跳天數；正式公開前把 `game.debug` 改成 `false`
- **劇情**：寫在 `data.js` 的 `scenes`（旁白、台詞、換背景、選項、跳轉、條件、效果），主線劇情排在 `story`（第幾天、早上或放學，時間到就自動播）。第一次開始遊戲時輸入名字，劇情／KakaoTalk／通話裡的 `{name}` 會換成玩家的名字。開發頁可以直接播放任何一段劇情、改名字。劇情中右上角「紀錄」旁有「存檔」，存完或按返回就回到劇情；讀這個存檔會從存檔的那一句繼續（結局進行中不能存檔）
- **好感度**：每次去一個地方，會從會出現在那裡的成員裡隨機遇到 1 位～全部；每次的總量固定（好感 6、關係 15），平分給遇到的人。有安排日程、沒有劇情的日子會用一句話顯示「去了哪裡、遇到誰」。星期日可以選一位或兩位成員見面；14 日可以送禮給一位，或請 A 送給 B
- **結局**：主線劇情裡寫 `{ ending: "結局id" }` 進入結局（`data.js` 的 `endings`）：結局劇情 → 條件成立的後日談 → END 畫面（點一下回到手機；重新開始只在設定裡）。戀人＝好感度到門檻＋告白旗標、成員 CP＝關係到門檻＋旗標、喚醒＝六位覺醒度都夠（門檻寫在 `romance`）。看過的結局記在 設定 → 結局圖鑑（重新開始不會清掉，可重看）
- **KakaoTalk 選項式回覆**：好友或群組寫 `choices`，輸入框上方出現選項；排成一行可以左右滑，點了文字放進輸入框（不能修改，點別的選項＝換掉），按送出才傳。每組只能選一次，可以寫 `if`、`effects`、`flag`、`reply`（格式寫在 `data.js` 好友 C 的註解）
- **存檔**：設定 → 存檔與讀檔（手動存檔格數 = `game.saveSlots`）。存檔放在 `riiiizeSaves`，「重新開始」不會清掉
- **重新開始**、**繁體／简体**：設定 App
- **上滑回首頁**：在 App 裡從畫面最下方往上滑（電腦可用滑鼠拖底部橫條）
- 進度存在瀏覽器 localStorage（key 都是 `riiiize-` 開頭，不會和 sosho 互相影響）
