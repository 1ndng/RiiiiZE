# RiiiiZE

模擬手機畫面的網頁遊戲框架（從 sosho 移植功能）：手機密碼鎖、首頁（行事曆小工具）、Instagram、KakaoTalk（含語音通話）、相簿、X、備忘錄。
目前只有功能，所有內容都是佔位用的測試資料，照片全部是 `images/placeholder.jpg`。

- 手機直接開就是滿版；電腦上會顯示成一支手機。
- **標題畫面**（`js/title.js`）：打開網頁先看到遊戲名稱（`data.js` 的 `title`）。有進度時「繼續／讀取存檔／從頭開始」，沒進度時「開始遊戲」。讀檔、時間循環、重新開始之後不會再出現一次
- **劇情的自動、快轉**：對話框右上角「自動」= 一句講完自己接下一句；「快轉」= 看過的台詞直接跳過，遇到沒看過的或要選擇時停下。看過的台詞記在瀏覽器裡（`riiiizeSeen`），時間循環的第二輪可以直接快轉
- **第一次遊玩**（`js/intro.js`）：輸入名字 → 生日 → 上傳照片（當 App 裡的頭貼，直接按下一步就用預設頭貼）→ 是否開始遊戲 → 鬧鐘（7:00，往右滑停止）→ 鎖定畫面，密碼是玩家生日（例如 10/14 → 1014）→ 主畫面上播開場對話 → 自由探索手機（點行事曆上成員生日有一句台詞；看到成員的照片超過 1 秒就結束探索：KakaoTalk 一打開、IG／X 點進成員主頁、相簿裡寫了 `cast` 的照片；秒數是 `intro.seeMs`）→ 畫面變黑、顯示 9/1 的日期 → 9/1 主線（手機上的時間從 7:58 開始，`intro.dayTime`）。劇情可以寫 `{ bg: "phone-dim" }`（看得到手機但變暗）、`{ wait: 1000 }`（停頓一秒）、`shake: true`（這句出現時畫面晃動）。開場台詞在 `data.js` 的 `scenes.intro_*`。手機以外的畫面預設背景是 `images/bg/school.jpg`（`storyBg`）。鎖定畫面的通知每則分開顯示，往上滑才輸入密碼；點通知解鎖後直接打開那個聊天室。
- 測試用密碼：手機、KakaoTalk、IG 帳號、相簿「已隱藏」、鎖住的備忘錄都是 `0000`。
- 通話：KakaoTalk 和「好友 A」的聊天室右上角電話鍵 → 會接通測試對話；打開「好友 B」聊天室 6 秒後會有來電。

## 其他

- **一學年**：2025/9/1（星期一）～2026/8/31。9/1～9/7 是開學週（主線＋強制日程），之後每個月開始時在月曆上安排星期一～六要去哪裡；確認後自動往後跳、照安排加好感。手機只有星期日能用：星期日先在黑底日期畫面上播劇情、選要見誰（出去玩），全部結束後才出現鎖定畫面，解鎖後自由使用手機（手機上的時間從 22:00 開始走，`game.nightTime` 可以改），按「睡覺」繼續。除了第一次遊玩的開場和這個時候，其他時間都不會出現鎖定畫面；其他有事的日子（主線、特殊劇情、節日、生日、14 日送禮）不解鎖手機，直接在黑底日期畫面上播劇情，播完自動往後跳。設定都在 `data.js` 的 `plan`。桌布的月曆可以用 ‹ › 翻月份（9 月～隔年 8 月）。每日聊天（`kakao.dayChats`）：那天的主線劇情結束後自動打開手機進入指定聊天室，聊完（按「繼續」）才進入下一天；星期日聊完直接自由使用手機。9/1 元彬、9/2 學生會群組、9/3 志工活動群組、9/4 成燦、9/5 社團活動群組、9/6 恩奭、9/7 KTV 群組（內容待寫）；同一天可以有好幾段（每段寫 `id`），`intro` = 打開聊天室後先播的劇情（旁白）。9/7 KTV 群組聊完後，客服小精靈會傳玩法說明（每月安排、日程、星期日、14 日、存檔、睡覺）
- **隱藏數值**：好感度（玩家對每位成員）、成員之間的關係（兩兩一組）、覺醒度。成員寫在 `data.js` 的 `cast`（大頭照寫 `avatar`，放在 `images/cast/`；沒寫就用預設頭貼。KakaoTalk 好友、IG 帳號、X 帳號寫 `cast: "m1"` 就是那位成員，名字和大頭照自動用 `cast` 的；玩家和六位成員一開始就認識：KakaoTalk 都是好友（不用密碼）、IG 互相追蹤、X 互相跟隨（`data.js` 最上面的 `IG_ALL`、`X_ALL`）；成員的 IG 帳號都不能登入。成員在 App 裡的顯示名字照 SOSHO（KakaoTalk：Shotaro、은석、성찬、원빈、소희、Anton；IG、X：SHOTARO、BLACK SHADOW、🦌、원빈、이소희、Anton）。KakaoTalk 點好友的頭貼或聊天室上方的名字會打開個人檔案，名字旁的筆可以改備註（只有玩家看得到，清空就恢復）。帳號 id 沿用 SOSHO：shotaroo0、seokkkk、sungchan913、bin032、252525252_、antonnie。KakaoTalk 群組寫 `activity: "club"` 就自動放進那個日程會出現的成員）；選項、訊息回覆、電話段落寫 `effects` 改數值，劇情、訊息、電話、行事曆行程寫 `if` 加條件（格式寫在 `cast` 上面的註解）。開發時可以在 設定 → 數值（開發用）查看、調整、跳天數；正式公開前把 `game.debug` 改成 `false`
- **劇情**：寫在 `data.js` 的 `scenes`（旁白、台詞、換背景、選項、跳轉、條件、效果），主線劇情排在 `story`（第幾天、早上或放學，時間到就自動播）。第一次開始遊戲時輸入名字，劇情／KakaoTalk／通話裡的 `{name}` 會換成玩家的名字。開發頁可以直接播放任何一段劇情、改名字。劇情中右上角「紀錄」旁有「存檔」，存完或按返回就回到劇情；讀這個存檔會從存檔的那一句繼續（結局進行中不能存檔）
- **好感度**：每次去一個地方，會從會出現在那裡的成員裡隨機遇到 1 位～全部；每次的總量固定（好感 6、關係 15），平分給遇到的人。有安排日程、沒有劇情的日子不再一天一句，改成停下來之前用「這週的放學後」卡片一次列出每天去了哪裡、遇到誰（之後想在每週回顧裡加隨機事件、小劇情，在 `js/plan.js` 的 `weekCard` 加）。星期日可以選一位或兩位成員見面；14 日可以送禮給一位，或請別人送（先選送禮的人，再選收禮的人）。背景：日程的 `bg`（`plan.activities`）用在那個日程的一句話、特殊劇情、主線強制日程；`plan.homeBg` 是回家、星期日早上和待在家；`weekend.bg` 是星期日出去玩
- **六人的覺醒劇情（樣板）**：`data.js` 的 `scenes.awake_m1_1`～`awake_m6_3`（1 = 異常察覺、2 = 記憶浮現、3 = 認知與接受），每段最後覺醒度 +1，三段都看過就算覺醒。還沒排進遊戲：寫好後用特殊事件（`plan.specials`）或固定日期（`story`）排，例子寫在樣板上方的註解
- **結局（三個）**：8/31 的 `final_choice`。六位都覺醒 → 選「喚醒大家」= **TRUE END**、「讓大家留在這裡」= **DREAM END 1**；有人還沒覺醒 → 直接 **DREAM END 2**。個人覺醒 = 覺醒度到 `romance.awake.value`，而且看過那位成員第三階段的覺醒劇情（旗標 `scene_awake_m1_3`，可在 `romance.awake.flag` 改）。條件可以寫 `awakened: "m1"`、`notAwakened`、`awakeCount: ">=3"`。結局劇情 → 條件成立的後日談 → 結局畫面（點一下回到手機；重新開始只在設定裡）。看過的結局記在 設定 → 結局圖鑑（重新開始不會清掉）。v0.1 沒有戀愛線，但好感度、成員關係值照樣保留
- **時間循環**：DREAM END 1、2 之後（`after: "loop"`）會自動存一個「循環前的存檔」（設定 → 存檔與讀檔，只能讀取），然後回到 2025/9/1 重新過這一年：數值、旗標、聊天都重置，名字、生日、頭貼保留，直接從鬧鐘開始。遊戲記得現在是第幾輪，條件可以寫 `loop: ">=2"`（第二輪才出現的台詞、照片、貼文）。讀取循環前的存檔後，8/31 晚上睡覺也會回到 9/1。設定裡的「重新開始」會回到第 1 輪
- **頭痛**：劇情步驟加 `headache: true`，這句出現時背景一陣一陣模糊（開場和 9/1 的頭痛台詞已經套上）
- **App 內容什麼時候出現**：IG 的貼文、限時動態、精選，X 的貼文和回覆，相簿照片，備忘錄，都可以寫 `from: "09-15"`（那天起才出現）或 `if: 條件`（例如 `{ awakened: "m3" }`、`{ loop: ">=2" }`）；沒寫 = 一開始就有
- **KakaoTalk 選項式回覆**：好友或群組寫 `choices`，輸入框上方出現選項；排成一行可以左右滑，點了文字放進輸入框（不能修改，點別的選項＝換掉），按送出才傳。每組只能選一次，可以寫 `if`、`effects`、`flag`、`reply`（格式寫在 `data.js` 好友 C 的註解）
- **存檔**：設定 → 存檔與讀檔（手動存檔格數 = `game.saveSlots`）。存檔放在 `riiiizeSaves`，「重新開始」不會清掉
- **重新開始**、**繁體／简体**：設定 App
- **上滑回首頁**：在 App 裡從畫面最下方往上滑（電腦可用滑鼠拖底部橫條）
- 進度存在瀏覽器 localStorage（key 都是 `riiiize-` 開頭，不會和 sosho 互相影響）

## 自動測試

改完劇情或程式後，在專案資料夾執行：

```bash
node tools/test.js
```

會自動跑 12 項主要流程（標題、第一次遊玩、開學週、每週回顧、星期日、送禮、三個結局、時間循環、存讀檔、快轉、App 內容解鎖），全部通過就沒問題。第一次要先安裝 Playwright：

```bash
npm i -D playwright
```

```bash
npx playwright install chromium
```
